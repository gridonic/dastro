# Localization (i18n)

Reference for the `i18n` block of `src/config/dastro.config.ts` and the locale helpers of `i18n()`.

## Options

| Option | Values | Default | Meaning |
|--------|--------|---------|---------|
| `defaultLocale` | a site locale | required | Locale without prefix in `prefix-except-default`; root redirect fallback in `prefix-always` |
| `locales` | site locales | required | All locales, in order |
| `routingStrategy` | `'prefix-except-default'` / `'prefix-always'` | required | Whether the default locale gets a prefix |
| `localePrefix` | `'language'` / `'locale'` | `'language'` | What the locale prefix is derived from |

## `localePrefix`

`'language'` (default) keeps the behaviour of every release before this option. `'locale'` is for sites with several locales of one language (`de_CH` and `de_DE`), which collide on `/de` in `'language'` mode.

| | `'language'` | `'locale'` |
|---|---|---|
| Locale prefix of `de_CH` | `/de` | `/de-ch` |
| Locale prefix of `en` | `/en` | `/en` |
| Prefix → locale | first locale starting with the prefix | exact match; `/de/…` is not a prefix of `de_CH` |
| Upper-case prefix (`/de-CH/…`) | not a prefix | 301 to `/de-ch/…`, query string kept |
| `<html lang>`, hreflang | `de` | `de-CH` (language tag) |

`localePrefix` is independent of `routingStrategy`: with `prefix-except-default` the default locale still has no prefix, and its home is `/`.

```ts
i18n: {
  locales: ['de_CH', 'fr_CH', 'en', 'de_DE'],
  defaultLocale: 'en',
  routingStrategy: 'prefix-always',
  localePrefix: 'locale',
}
```

Switching an existing site to `'locale'` changes every prefixed URL (`/de/…` → `/de-ch/…`). Dastro does not redirect the old URLs; add those redirects in the project.

## Helpers

From `i18n()` (`Astro.locals.dastro.i18n()` or `i18n(config)`). All follow `localePrefix`.

| Helper | `'language'` mode | `'locale'` mode | Use for |
|--------|-------------------|-----------------|---------|
| `localePrefix(locale)` | `de_CH` → `de` | `de_CH` → `de-ch` | Building URLs by hand, e.g. a home-URL fallback `/${localePrefix(locale)}` |
| `localeLangTag(locale)` | `de_CH` → `de` | `de_CH` → `de-CH` | `lang` attributes, hreflang, values sent to tracking or forms |
| `localeFromPrefix(prefix)` | `de` → first `de…` locale | `de-ch` → `de_CH`, `de` → `undefined` | Reading the locale of a path segment |
| `localePrefixMode` | `'language'` | `'locale'` | Branching on the mode |

Prefer `resolveRecordUrl(record, locale)` from `routing()` over hand-built URLs; it already uses `localePrefix`.

`normalizedIsoLocale(locale, keepVariant?)` is **deprecated**. It still works and ignores `localePrefix`, so in `'locale'` mode it returns the wrong prefix (`de` instead of `de-ch`). Replace it with `localePrefix` (URLs) or `localeLangTag` (language values).
